01RBCheck

A spending dashboard built from bank text messages

Canadian banking apps give you almost no spending insight — but RBC texts you every transaction. RBCheck mines those SMS alerts out of the macOS iMessage database and turns them into a live personal finance dashboard.

  • Queries the iMessage chat.db SQLite database directly, extracting RBC alerts embedded inside binary attributedBody blobs
  • Regex parsers classify deposits, withdrawals, card purchases, payments, and refunds — pulling amount and merchant from raw SMS text
  • FastAPI + PostgreSQL backend with endpoints for daily / weekly / rolling / monthly summaries, plus date-range, merchant, and price filters
  • Dedup pass drops withdrawal ↔ credit-card-payment pairs that land within 60 seconds of each other, even across poll cycles
  • Chart.js dashboard client, Dockerized server, CORS-scoped to gwanwoo.dev

02YOLight

Lights that turn on because a neural net saw you

YOLight points a YOLOv8 model at a webcam and drives Govee smart lights over the local network — walk in, lights on; leave, lights off. No motion sensors, no cloud account: it speaks Govee's UDP LAN protocol directly.

  • Real-time person detection with Ultralytics YOLOv8 + OpenCV, on CUDA when a GPU is available
  • Discovers lights via multicast (239.255.255.250) and sends raw per-device UDP control packets — no vendor SDK
  • The interesting bug: brief occlusions (reaching behind a door, ducking behind a chair) read as "room empty" and cut the lights
  • Fix: an occupancy state machine — instant on, 3-second debounced off — cut false turn-offs from ~31/day to ~9/day, a ~70% reduction
  • Documented V2–V5 roadmap: doorway occupancy counting, RealSense depth sensing for darkness, pose-based gesture control
